# Riyadh Villa Price Estimator

مشروع لتقدير أسعار الفلل السكنية في مدينة الرياض بالاعتماد على خوارزميات تعلم الآلة ومعايرة مؤشر عقار لأسعار 2026. هذا المشروع تجربة بحثية وتقديرية ولا يُعد تقييماً عقارياً معتمداً.

## حدود النموذج ومواطن الضعف (Limitations)

- **الفترة الزمنية للبيانات الأساسية**: تم جمع بيانات `Aqar_data.csv` خلال فترة 2015–2016. التنبؤات الحالية لعام 2026 تعتمد على معامل نمو مؤشر عقار، وليست مبنية على صفقات حية مباشرة لكل عقار.
- **شرائح الأداء الأقل دقة (Worst Performing Slices)**:
  - الفلل بمساحة أكبر من 600 م²: الخطأ المطلق MAPE يرتفع إلى 25.36% (MdAPE بلغ 18.22%، ن = 160).
  - الفلل ذات الأسعار الأعلى من 3,500,000 ريال: MAPE بلغ 16.56% مع انحياز بالوسيط قدره -10.37% (يميل النموذج لنقص التقدير في الفئات الفاخرة، ن = 83).
  - حي الدار البيضاء: أعلى خطأ بين الأحياء الرئيسية حيث سجل MAPE قدره 22.41% (ن = 23).
- **طبيعة الأسعار**: الأسعار المسجلة هي أسعار عرض في إعلانات وليست أسعار صفقات بيع فعلية مسجلة لدى البورصة العقارية.
- **تغطية مؤشر عقار**: ثمانية أحياء فقط تمتلك سلاسل تاريخية مباشرة في المؤشر، بينما تحصل بقية الأحياء على وسيط الرياض لنفس فئة المساحة.

### نتائج الاختبارات المقترنة (Paired Comparison vs HGB Tuned)
- مقارنة HGB مع Dummy: تفوق واضح للنموذج (اختبار ويلكوكسون p = 0.0000، فرق الوسيط -0.1671).
- مقارنة HGB مع Ridge: تفوق واضح للنموذج (اختبار ويلكوكسون p = 0.0000، فرق الوسيط -0.0140).
- مقارنة HGB مع GBR: فرق غير واضح (اختبار ويلكوكسون p = 0.1750، فرق الوسيط -0.0015).
- مقارنة HGB مع Relative GBR: فرق غير واضح (اختبار ويلكوكسون p = 0.4525، فرق الوسيط -0.0005).

## تدقيق البيانات والتنظيف (Data Audit)

- البيانات الخام: 9,974 صفاً.
- حذف التكرار المطابق: 2,500 صفاً مكرراً أزيلت (العدد بعد الحذف: 7,474).
- حدود السعر (150,000 إلى 7,000,000 ريال) والمساحة (100 إلى 1200 م²): استبعاد 237 صفاً (المتبقي: 7,237).
- استبعاد القيم الشاذة لسعر المتر (أقل من 1,000 أو أكثر من 15,000 ريال/م² كأخطاء إدخال): 16 صفاً من التدريب و3 صفوف من الاختبار.

## بنية المشروع وطريقة الاستخدام

```text
├── data.py                   # تحميل وتدقيق البيانات وتقسيم المجموعات الصارم
├── features.py               # المصدر الموحد لاستخراج الميزات (معالجة النصوص وتسميات الأحياء)
├── modeling.py               # خطوط الأنابيب ومعالجة القيم المفقودة ونماذج التقدير
├── train.py                  # تشغيل التجارب، التدريب، الضبط، وحفظ النتائج
├── evaluate.py               # تحليل الشرائح والأخطاء الأكثر تبايناً
├── inference_example.py      # مثال استدلالي محلي لتقدير عقار مفرد
├── api.py                    # خدمة FastAPI لتقديم التنبؤات والتحقق من المدخلات
├── aqar_benchmark_mapper.py  # مطابقة الأحياء والمساحات مع مؤشر عقار السكني
├── tests/                    # 39 اختبار فحص تسرب وتطابق ومطابقة وتراجع
└── reports/                  # تقارير التدقيق والتجارب والشرائح بصيغة JSON و Markdown
```

### 1. التثبيت والتشغيل
```bash
pip install -r requirements.txt
```

### 2. تدريب النموذج وتقييمه
```bash
python train.py
python evaluate.py
```

### 3. تشغيل الاختبارات المؤتمتة
```bash
pytest tests/
```

### 4. تجربة تقدير سعر عقار
```bash
python inference_example.py
```

### 5. تشغيل واجهة الاستدلال (API)
```bash
uvicorn api:app --reload --port 8000
```
يمكن استعراض التوثيق التفاعلي للخدمة عبر `http://localhost:8000/docs`.
